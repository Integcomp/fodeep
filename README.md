# Fo' Deep

Band site for **Fo' Deep** — Oceanside, CA hip-hop.

- Music: [Ride](https://music.apple.com/us/album/ride/1779505713?i=1779505715) and [Novocaine](https://music.apple.com/us/album/novocaine/1867064043?i=1867064258)
- Instagram: [@fodeep760](https://www.instagram.com/fodeep760/)
- Booking form (optional email via [Web3Forms](https://web3forms.com))

## Local

```bash
npm install
npm run dev
```

## Booking email

Copy `.env.example` to `.env` and set `VITE_FORM_ACCESS_KEY` from Web3Forms. Until then, the form asks people to DM Instagram.
